# Wristify's dock

Une barre des taches facon macOS pour Windows 10 et 11.

## Installation

Telecharge le fichier `.zip` de la derniere version dans l'onglet **Releases** (a droite de cette page), puis decompresse-le (clic droit sur le dossier -> Extraire tout).

Lance ensuite **installer.bat**. Windows peut afficher un avertissement SmartScreen : clique sur *Informations complementaires*, puis *Executer quand meme*.

Au premier demarrage, l'appli demande une **cle d'activation**. Entre la cle qui t'a ete fournie : sans cle valide, l'appli ne demarre pas.

## Mises a jour

L'appli verifie les nouvelles versions automatiquement et propose de les installer. Rien a refaire a la main.

## Cle d'activation

Chaque cle est personnelle. Pour en obtenir une, contacte le proprietaire du dock.
